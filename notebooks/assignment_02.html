Question 1: Sunflower Center Detection via Scale-Space LoG Extrema¶

Sunflower heads feature dark central floret disks on bright yellow petals ($\nabla^2 I > 0$). The positive scale-normalized Laplacian $\sigma^2 \nabla^2 (G_\sigma * I)$ peaks at disk centers with characteristic radius $r = \sqrt{2}\sigma$.

  • Coordinates: Reported in 1/4-reduced image space (cv2.IMREAD_REDUCED_COLOR_4, $360 \times 360$ px).
  • Scale sampling: 24 logarithmic scales from $\sigma_{\\min} = 1.50$ px to $\sigma_{\\max} = 12.50$ px ($r \in [2.12, 17.68]$ px).
  • Four candidate filters: (1) Horizon row cutoff $y \ge 0.51 H = 184$ px; (2) Dilated HSV petal envelope ($H \in [14, 36], S,V \ge 70$); (3) Grayscale dark disk test $I(x, y) \le 0.48$; (4) LoG peak response $\ge 0.035$. Boundary margin $x, y \in [6, 354]$ px suppresses border reflections.

Question 2: Robust Line and Circle Fitting via Sequential RANSAC¶

Point set $X$ ($N=100$) contains 50 line points ($y = -x + 2, \sigma=1.0$) and 50 circle points ($c=(2, 3), r=10, \sigma=0.625$) from Listing 1.

  • Line model: Unit normal $[a, b]^\top$ ($\|[a, b]\|=1$), offset $d$: $a x + b y = d$. Error $e = |a x + b y - d|$. Threshold $T = 0.85$. Refitted via Total Least Squares (TLS) SVD on consensus points.
  • Circle model: Center $(x_0, y_0)$, radius $r$ from 3-point circumcenters. Distance threshold $T = 0.85$. Refined via Nelder-Mead.
  • Consensus size & iterations: Setting minimum consensus $T_{\\min} = 30-35$ ensures $\ge 60-70%$ true model participation while preventing noise clusters from forming models. By $N = \frac{\ln(1 - p)}{\ln(1 - w^s)}$ with confidence $p = 0.99$:
    • Line ($s=2, w=0.5$): $N = \frac{\ln(0.01)}{\ln(1 - 0.25)} \approx 16$ iterations ($22$ for $p=0.999$).
    • Remnant circle ($s=3, w \approx 0.84$): $N = \frac{\ln(0.01)}{\ln(1 - 0.84^3)} \approx 5$ iterations. 500 iterations guarantee ample theoretical safety.

Question 2(d): Analysis of Circle-First Fitting¶

  • Line inlier intersection crossing: Line-first consensus (45 inliers) captures 41 true line points and 4 circle points where the line cuts through the circle circumference ($|a x + b y - d| < 0.85$).
  • Honest report on circle-first RANSAC: Running circle RANSAC on full cloud $X$ recovers center $(2.08, 2.91)$ and $r = 9.87$ with 47 inliers. It is partly degenerate and contaminated: it absorbs 42 circle points and 5 intersecting line points (Figure 2.2). Subtracting this consensus strips away those 5 line points, fragmenting the line into disconnected segments.
  • Degenerate arc tendency: 3 collinear points from the line tend to define low-curvature, high-radius circumcircles ($r > 500$) sweeping up $\approx 40$ collinear points, creating flat pseudo-line arcs.
  • Sampling probability: Line fitting requires $s=2$ ($P = 0.5^2 = 0.25$); circle requires $s=3$ ($P = 0.5^3 = 0.125$). Line-first succeeds $2\times$ faster and leaves an uncontaminated remnant for circle refinement.

Question 3: Planar Homography Warping and Flag Blending¶

A planar homography is a $3 \times 3$ projective matrix $\mathbf{H}$ (8 degrees of freedom) relating coplanar points across views: $\mathbf{x}' \sim \mathbf{H}\mathbf{x}$.

  • Direct Linear Transformation (DLT) via SVD: For 4 corner correspondences $\mathbf{x}_i \leftrightarrow \mathbf{x}'_i$, the $8 \times 9$ algebraic system $\mathbf{A}\mathbf{h} = \mathbf{0}$ is solved via SVD $\mathbf{A} = \mathbf{U}\mathbf{\Sigma}\mathbf{V}^\top$. Vector $\mathbf{h}$ is the right singular vector associated with the smallest singular value ($\sigma_9 \approx 0$). In OpenCV, cv2.findHomography implements this normalized DLT algorithm.
  • Alpha blending: The flag image is warped into the facade quadrilateral and blended using transparency mask $M$: $I_{\mathrm{blend}} = (1 - \alpha M) \odot I_{\mathrm{arch}} + (\alpha M) \odot I_{\mathrm{warped}}$.

def dlt_homography(src, dst):
    A = []
    for (x, y), (u, v) in zip(src, dst):
        A.extend([[-x, -y, -1.0, 0.0, 0.0, 0.0, u * x, u * y, u], [0.0, 0.0, 0.0, -x, -y, -1.0, v * x, v * y, v]])
    _, _, Vt = np.linalg.svd(np.asarray(A, dtype=np.float64)); H = Vt[-1].reshape(3, 3)
    return H / H[2, 2]

Answer to Question 4(e): Causes of High Component Differences¶

  1. 3D Projective Parallax: Homographies assume planar scenes. Tall parts (~11 mm USB port, electrolytic capacitors) exhibit viewpoint parallax that planar $\mathbf{H}$ cannot align.
  2. Cast Shadows: Directional lighting causes tall parts to cast moving shadows, creating large residuals even on undamaged boards.
  3. Residual Edge Misregistration: High-contrast step edges (traces, silkscreen) produce bright boundary fringes from sub-pixel warping and lens distortion.
  4. Specular Reflections & Glints: Metallic shields and solder joints produce viewpoint-dependent glints, causing localized saturated spots.
  5. Physical Component Variations: Distinct board revisions feature relocated, substituted, or missing components.
